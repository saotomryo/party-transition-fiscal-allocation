# 公開用データ

出典：政府統計の総合窓口(e-Stat)・総務省の地方財政状況調査、住民基本台帳に基づく人口、人口動態及び世帯数調査、および総務省の衆院選公式結果。

本プロジェクトが加工したデータであり、政府が作成・公表した分析結果ではありません。加工内容は自治体コードの結合、金額の円換算、人口当たり換算、当選時党派分類、前後平均、条件調整。集計・除外の詳細はREADMEとdocs/article-evidence/methodology.md、元資料URLはdocs/article-evidenceの出典JSONを参照。

e-Stat利用規約：https://www.e-stat.go.jp/terms-of-use

規約は複製・公衆送信・加工・商用利用を認め、数値データ等は著作権の対象外と説明しています。第三者の権利がある素材、ロゴ、個別の特別条件などは別扱い。本配布にはニュース本文、政府・政党のロゴ、原本PDFやHTMLは含みません。独自のライセンスで元資料の権利を上書きしません。

固定版：2026-10-13。自動更新はしません。host側で原本取得・分析後、`python scripts/package_public_data.py`で再作成し、検証してコミットします。manifest.jsonに各ファイルのSHA256を記録。
