# 全国市町村の財政配分変動モニター

公式公開ファイルを使う記述的分析MVP。政治的介入の推定・断定は行わない。各変動の理由は「説明未確認」と表示する。

## 起動

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python finance.py --start 2015 --end 2024
.venv/bin/streamlit run app.py
```

収集・依存インストール・ブラウザ操作はhost側で実行する。APIキー不要。ネットワーク取得はアプリ閲覧から分離している。自動化する場合もhost prepare、Codex確認、host finalize、reportに分ける。

## 公式ソースと定義

- [e-Stat 地方財政状況調査](https://www.e-stat.go.jp/stat-search/files?layout=dataset&toukei=00200251&tstat=000001077755&tclass1=000001077756&tclass2=000001077757)：歳入内訳と表紙。
- [住民基本台帳に基づく人口、人口動態及び世帯数調査](https://www.e-stat.go.jp/stat-search/files?layout=dataset&toukei=00200241)：総計・市区町村別人口。
- [総務省 市町村別決算状況調](https://www.soumu.go.jp/iken/zaisei/r06_shichouson.html)：補助的な照合先。

調査年から1を引いた決算年度をCSV実値で検証する。自治体コードはチェック桁を含む6桁文字列。団体区分1–5・8・9（市町村・特別区）を採用し、一部事務組合・全国計・政令市行政区を除外する。金額は原本の千円から円へ変換。財政力指数は原本整数表示を100で割る（3年度平均）。人口は決算年度翌年1月1日の日本人＋外国人総計。

地方交付税＝普通交付税＋特別交付税＋震災復興特別交付税の整合性を検証する。特別交付税は震災復興分と分けて取得する。欠測をゼロ補完しない。前年比は連続年度のみ、前年ゼロの比率は欠測とする。

## 生成ファイル

- `data/raw/`：公開原本と一覧キャッシュ
- `data/collection-report.json`：URL、取得確認時刻、SHA256、年度別失敗
- `data/panel.parquet`：加工データと前年比・人口当たり値
- `data/finance.duckdb`：`municipal_finance`テーブル

年度取得に失敗した場合は報告を書き、既存panelを更新しない。再実行時は取得済み原本を再利用する。更新版を取得する場合は該当キャッシュを退避して再収集する。

## 比較と限界

同年度・同団体区分から、log(人口比)と財政力指数差/0.2のユークリッド距離で近い自治体を選ぶ。公式類似団体区分ではない。選定数・変動率・変動額の閾値は可変。合併の遡及補正、災害、物価、全国予算規模、申請額、採択率を使う説明・因果評価は未実装。衆院選の記述的な照合は後述の機能で確認できる。財政額の変化は国側の配分判断だけを意味しない。

次段階では自治体コード履歴、選挙区境界と自治体の対応、政治家交代・推薦支持・予算決定日の政権構成を別テーブルで管理する。記述的比較と因果推論を分離する。

## 衆院選の前後確認（2026-10-12追加）

変化率の絶対値が大きい自治体から選び、小選挙区の当選者・選挙時点の党派・全候補者得票・前回結果・公式資料を確認できる。

```bash
.venv/bin/python elections.py
.venv/bin/python certify_results.py
.venv/bin/streamlit run app.py
```

財政取得とは別のhost収集処理。総務省の結果一覧→市区町村別得票一覧→都道府県別公式Excelを取得し、原本・URL・SHA256・取得確認時刻を保存する。アプリ閲覧中には外部取得しない。再収集した場合は必ず `certify_results.py` も実行する。

対象は2014/2017/2021/2024年衆議院総選挙。2014年295区、他年289区、計1,162選挙区。現在の財政データ範囲との関連を確認するための対象であり、最新選挙までを網羅するものではない。参院選・首長選・補選・比例復活・選挙後の所属変更は未収録。

### 時間の扱い

選挙実施年度は4月開始の年度で計算し、「選挙前の通年年度」「選挙実施年度」「選挙後の通年年度」を区別。前後比較は実施年度の前年と翌年（例：2021年選挙なら2020年度と2022年度）。選挙年の決算を事後の通年実績としない。2024年選挙は2025年度決算が未収録のため事後比較不可。これは記述的比較であり、予算の決定時点・申請行動・政権との関係や因果効果を表さない。

### 自治体と選挙区の対応

公式得票表の地域名を財政側の同時期自治体名へ対応させる。政令市行政区は同年の公式住民基本台帳の行政区名から親市を確認して集約する。地域が複数の小選挙区に分かれる自治体は全対応区を表示し、財政額を選挙区間に配賦しない。ケ/ヶ・鯵/鰺などの表記差を正規化するが、同名・不明な地域名は推測しない。区割り改定があるため同じ選挙区番号を同一地域とみなさない。

自治体対応：2014年1,741 / 2017年1,739 / 2021年1,738 / 2024年1,741自治体。2017年3行・2021年4行は原本名称との対応未確認（例：東京都の「稲敷市(21区)」、鹿児島県の「大崎市」）。原本を勝手に訂正せず、収集記録に残す。

### 正式当選表との照合と原本の不整合

全国の候補者別当落表（総務省PDF/Excel）から当選表示・氏名・党派・得票を独立取得。1,162区の当選表示を収録し、1,161区で市区町村別表の最多得票と一致した。2021年大阪19区は市区町村別表の選挙区合計13,295票と正式当選表68,209票が不一致。画面の当選情報には正式当選表を採用し、旧値・出典・要照合状態を保存する。

ほかに2017年福井1区、2021年宮城3区の市区町村合算と選挙区計が不一致、2021年神奈川9区で1候補者の選挙区合計欠測を検出。欠測合計は市区町村得票から算出した値として明示する。最多得票と正式当選の区別、候補者名のかな・漢字表記差を保つ。2021年東京2区はPDFの氏名文字を抽出できず、正式当選得票が一致する公式市区町村別表から氏名を補完したことを明記する。

政党名は選挙時の届出表記。個別選挙の閲覧画面では与党/野党を自動分類しない。全国比較では別途確認した対象期間の政権参加を使う。候補者名や党派の変化だけから政治的介入を判断しない。

## 近年の党派交代と財政配分の探索的比較（2026-10-13追加）

画面上部の「全国の仮説比較」で、2017・2021年の小選挙区当選時党派の交代と国からの財政移転を比較できる。「自治体ごとの確認」で従来の変化率順位・個別選挙結果へ戻る。

```bash
.venv/bin/python alignment.py
.venv/bin/streamlit run app.py
```

全国の財政データ・公式当選表を準備済みなら、この分析処理はネットワーク不要。政党・連立確認の公式発表は `data/analysis/raw/` に別途保存済み。

### 検証対象と判定範囲

- 与党→野党を与党→与党と、野党→与党を野党→野党と比較する。
- 前回と今回の総選挙の当選時党派を観測として保存。対象期間の連立参加は自民党・公明党。**議員個人の連続党籍履歴、実際の予算決定時点の所属、期中離党・補選・比例復活は未整備**。現在の結果は党派観測ベースの探索的関連であり、厳密な議員影響力の検証完了を意味しない。
- 連立判定の確認対象期間は2012-12-26〜2024-03-31。終端は分析対象の上限であり連立終了日ではない。期間外・無所属・未確認党派は「未判別」。現在の政権構成を過去へ遡及適用しない。
- 各選挙年の1,741自治体全体を分類し、変化率の大きさでは選別しない。複数小選挙区、無所属等、原本名称未確認、前回と今回の選挙区番号または所属自治体集合が異なる地域を主分析から除外。自治体集合の一致は境界の完全一致を証明しない。
- 財政データが全対象年度そろい、選挙前年の人口・財政力指数があり、同じ都道府県×団体区分に交代群と継続群の両方が存在する範囲で比較。外挿を避けるため、候補全体より分析標本は少なくなる。除外一覧をCSV出力できる。

### 方法

選挙実施年度を除き、前後各1年度または各2年度の平均を比較する。例：2021年の2年度比較は2019・2020年度と2022・2023年度。自治体ごとの毎年の人口で割った名目円を使い、各自治体を等しく重み付けする。単純な変化率の高い地域だけを比較しない。

交代群と継続群の配分変化の差を、選挙前年のlog人口・財政力指数・都道府県・団体区分で調整する。OLSの地域ダミーは重複を除いて全列独立にする。自治体固定の差は前後差分で除く。全国共通の支出変化は同時期の継続群との差で比較する。ただし、地域別の災害・産業構造・人口年齢構成・首長・申請行動の差等は残るため、因果効果とは呼ばない。

標準誤差は同じ小選挙区内の自治体の相関を考慮したCR1クラスターロバスト推定。95%区間は自由度「独立選挙区数−1」のt分布で計算。比較する片側の選挙区が3未満なら推定保留、10未満なら参考値として表示して仮説判断を保留する。これらは本MVPの保守的な表示ルールであり、小標本問題が解消する境界を意味しない。

2選挙×2窓幅×4項目×2仮説の32比較を事前定義。推定可能な24比較にBH補正を適用する。選挙前2年度の傾向差は同じ標本で別に調べ、その検定群を別途BH補正。事前差を検出しなくても平行トレンドは証明されない。画面の95%区間は個別区間で、同時信頼区間ではない。

### 支出内訳とコロナ・災害の確認

国庫支出金、特別交付税、普通交付税（制度算定の比較用）、国庫支出金から確認できたコロナ・災害復旧交付金を引いた値を別々に計算する。控除する親項目は「新型コロナウイルス感染症対応地方創生臨時交付金」「その他新型コロナウイルス感染症対策関係交付金等」「災害復旧事業費支出金」。原本の千円を円に変換する。子項目を重ねて引かない。2020年度より前はコロナ項目の制度対象前として0とし、欠測を0補完しない。

控除後の値も**全コロナ支出や全災害・復興支出を除いたものではない**。特別交付税の災害需要、震災復興特別交付税、年齢構成、物価、自治体の申請額・採択率の完全調整は未完了。

### 初回結果と限界

国庫支出金・前後2年度の調整後差（円／人）:

| 選挙 | 交代 | 調整後差 | 95%区間 | 交代／継続選挙区 | 解釈 |
|---|---|---:|---:|---:|---|
| 2017 | 与党→野党 | -15,031 | -40,601〜10,538 | 6／15 | 事例数が少なく保留 |
| 2017 | 野党→与党 | 算出保留 | — | 1／2 | 独立事例不足 |
| 2021 | 与党→野党 | -3,938 | -44,938〜37,062 | 20／44 | 明確な差を確認できず、影響なしの証明ではない |
| 2021 | 野党→与党 | -410 | -9,569〜8,749 | 5／4 | 事例数が少なく保留 |

内訳控除後の2021・野党→与党・2年度比較では増加方向の推定が出るが、交代5区・継続4区の小標本のため判断保留。結果を選択的に採用せず、全32比較を保存する。議員個人の党籍確認と地域の説明要因を追加してから、仮説の支持・棄却を再評価する。

## 公開画面の整理（2026-10-13）

公開方式はStreamlit。app.pyは「党派交代と財政配分の全国比較」のみを表示。考察・仮説判断の表示は除き、数値・方法・注釈を表示する。自治体画面はmunicipality_view.pyに保持し、必要時に `.venv/bin/streamlit run municipality_view.py` で起動できる。公開画面への再接続は後日可能。現在はローカル実行のみで、外部公開は未実施。

## Streamlit Community Cloudでの公開

Gitに含めたpublic_data/の加工済み固定版を読み込むため、サーバーでe-StatへのアクセスやAPIキーは不要。原本data/は引き続き非配布。自治体確認の保存用画面は従来のdata/を必要とする。

Community Cloudでリポジトリ `saotomryo/party-transition-fiscal-allocation`、ブランチ `main`、エントリポイント `app.py`、Python `3.12`を指定する。依存はrequirements.txt。Secretsの設定は不要。クラウドへの実際のデプロイとクラウド環境での確認は別途行う。

配布データの出典・加工表示はpublic_data/README.mdとアプリ内に掲載。原本再取得後の配布更新は `.venv/bin/python scripts/package_public_data.py` を実行してコミットする。
